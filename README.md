# 人物关系演化图

一个用于表现**故事角色与人物关系随剧情发展而演变**的可编辑关系图工具。角色是六边形节点，关系是带类型颜色的连线；底部进度条式时间轴上的每个时间点都保存一份独立的关系图快照，新建时间点可一键"继承"上一时间点的全部内容，在此基础上修改，即可直观表现角色自身与角色之间关系的发展变化。

**在线使用**：<https://zhengdaode.github.io/renwuguanxitu/>

纯静态单文件应用，无需安装、无需后端、可离线。

## 功能

### 关系图
- 六边形角色节点，拖动自动**磁吸**到六边形网格交点（网格可开关，作绘图指引）
- 角色展示方式可切换：**名称 / 符号 / Emoji / 图片**（图片内嵌存储）
- 七种关系类型（友情/爱情/亲情/师徒/竞争/敌对/其他）以颜色区分
- 连线上不显示文字，保持画面干净；**点击连线**自动聚焦到两端角色并在右侧面板显示关系详情；悬停显示悬浮提示

### 时间维度
- 进度条式时间轴，每个时间点可标注**年份/时间**
- **时期标注**：点选起点、终点刻度创建，横跨若干时间点的彩色条带；同一区间可**叠加多个**（自动分行），用于标记卷、篇章、时代
- 「对比上一时间点」自动标注差异：🟢 新增 · 🟠 变更 · 🔴 红色虚线 = 退场/消失
- 「▶ 播放」自动逐帧播放演变过程
- 新建时间点可选择**继承当前时间点**（深拷贝全部角色与关系）或空白开始

### 存储与导出
- **存储**：内容自动保存在浏览器本地（localStorage），刷新/重开不丢失
- **上传**：支持导入 JSON 项目文件；角色图片本地上传
- **编辑**：节点、连线、时间点、时期标注全部可视化编辑
- **导出**：JSON 项目文件（可再导入），或当前时间点关系图 **PNG** 图片

## 使用

| 操作 | 方式 |
|---|---|
| 添加角色 | 「＋ 角色」后在画布点击放置，或双击画布空白处 |
| 建立关系 | 「🔗 连线」依次点击两个角色 |
| 编辑 | 单击角色/连线/时期标注，在右侧面板修改；Delete 删除选中项 |
| 缩放/平移 | 滚轮缩放；拖动空白处平移 |
| 新增时间点 | 底部「＋ 新增时间点」，选择继承或空白 |
| 时期标注 | 「＋ 时期标注」→ 点起点刻度 → 点终点刻度 |

> 注意：数据存于浏览器本地，清理浏览器数据会丢失，请用「导出 JSON」定期备份。

## 本地运行

克隆仓库后直接双击 `index.html` 即可，或：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 技术说明

- 零依赖单文件（原生 JavaScript + SVG），无构建步骤
- 六边形网格与磁吸基于 pointy-top 轴坐标系（axial coordinates）实现
- PNG 导出通过克隆 SVG + 内联样式 + Canvas 光栅化实现
- 部署于 GitHub Pages，推送 `main` 分支即自动更新
